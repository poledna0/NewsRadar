# Preparar a página do GitHub

Use este documento para preencher manualmente a seção **About** do repositório e preparar lançamentos. Descrição e tópicos são metadados do GitHub; não fazem parte dos arquivos versionados.

## Descrição curta

```text
Self-hosted news and research radar. Discover, deduplicate and summarize news with SearXNG, RSS and local Ollama AI.
```

## Topics

Adicione estes tópicos na seção **About** do repositório:

```text
self-hosted, news-aggregator, news, research, rss, python, fastapi, ollama, local-ai, searxng, sqlite
```

## Checklist de lançamento

1. Confirme que o workflow `Testes` está verde na aba **Actions** após o push.
2. Em **Settings → General → Social preview**, carregue uma imagem própria do projeto (1280 × 640), sem dados reais de usuário, IPs, tokens ou capturas da tela administrativa.
3. Publique uma release quando o conjunto de funcionalidades estiver estável. Use notas com mudanças, migrações e instruções de atualização; não marque uma versão que ainda não foi testada.
4. Mantenha README em português e inglês atualizados, com instalação verificável, limites e links para documentação.
5. Convide contribuições específicas e pequenas. Issues devem descrever tarefas reais, não promessas artificiais.
6. Divulgue em comunidades de self-hosting, Python, RSS e Ollama somente quando houver uma versão utilizável; explique claramente os requisitos e limitações.

Estrelas dependem de utilidade, confiança, documentação e manutenção ao longo do tempo. Não compre estrelas, não use contas automatizadas e não faça spam: essas práticas prejudicam a reputação e podem violar as regras da plataforma.
