# Código de Conduta

A comunidade NewsRadar busca colaboração respeitosa, segura e construtiva.

Comportamentos esperados:

- Seja cordial e considere diferentes níveis de experiência.
- Critique ideias e implementações, não pessoas.
- Compartilhe problemas de segurança por canal privado, conforme `SECURITY.md`.
- Evite assédio, discriminação, ataques pessoais e publicação de dados privados.

Mantenedores podem editar, fechar ou remover conteúdo que viole estas regras e restringir a participação em caso de repetição ou gravidade. Para reportar uma situação, contate os mantenedores em privado pela aba Security do GitHub.
